# 印小单 · 商品建品中心

给已有 **商品中心 + ERP** 的团队用的建品 + 前端报价工具。  
不重复做商城、购物车、订单、支付和代理体系，只补三块：

1. **类目管理**：新增类目、排序、启停、商品归属。
2. **新的建品方式**：同一个入口下分「标准定价商品」和「非标计价商品」。
3. **手机前端非标报价器**：后台配置的尺寸公式、材料、工艺、包装、数量规则，直接生成客户可用的实时报价页面。

> 过去的商品只有标准定价；现在非标商品可以在建品时把展开公式、材料、工艺、拼版、机型和计价参数一起配置好，建完即可试算，并导出给 ERP/商品中心。  
> 同一个商品可以挂多个报价工厂（数码印刷、传统胶印、标签轮转、瓦楞水印），系统会按各自的设备与价格系数分别计算并比价。

## 一、快速启动

环境：Python 3.9+，零第三方依赖（SQLite + 标准库 HTTP Server）。

```bash
cd 印小单
python3 server.py
# 需要让同一 Wi-Fi 的手机访问时：
HOST=0.0.0.0 python3 server.py
```

打开：

**http://127.0.0.1:8787/**

| 入口 | 说明 |
|---|---|
| `/#/admin` | 建品后台（管理员登录后默认进入） |
| 账号 | `admin` / `admin123` |

可配置环境变量：

```bash
PORT=9000 python3 server.py
YXD_DB=/path/mall.db python3 server.py
YXD_DATA_DIR=/path/data python3 server.py
```

- 客户端商城、购物车、下单、支付。
- 订单管理、生产排程、发货。
- 代理商、佣金、渠道二维码。

## 三、两种建品方式

### 3.1 标准定价商品

适合：现货、标品、ERP 中已经有固定价格和 SKU 的商品。

| 字段 | 说明 |
|---|---|
| 商品名称 | 必填 |
| 商品编码 / SKU | 与 ERP 对齐 |
| 类目 | 必填，可选择已启用类目 |
| 标准售价 | 固定单价，不参与非标计算 |
| 计价单位 | 个 / 套 / 包 / 张 |
| 起订量、交期 | 用于展示和导出 |
| 图片、副标题、详情 | 前台展示用 |
| 状态 | 草稿 / 上架 / 下架 |

入口：**新建商品 → 标准定价商品**。  
标准商品不需要配置展开、拼版和工艺。

### 3.2 非标独立测算（9 步）

这是非标商品唯一的建品流程，不再分“快速/高级”两套入口：

1. **基础信息**：名称、类目、图片、描述。
2. **成品尺寸**：前端可输入的长/宽/高字段，各自最小/最大/默认值，关联展开公式，自动换算。
3. **拼版**：四周出血 3mm；选择工厂、机型和上机印张，把展开尺寸放到固定印张上，算一张拼几个。
4. **原辅料**：按商品勾选材料和辅料，显示名称、克重、图片、价格算法。
5. **生产工艺**：覆膜、烫金、模切、凹凸、裁切、UV 等；带适用材料和最低克重限制。
6. **包装方式**：包装、箱规、物流交付。
7. **定制数量**：一个起订量、最大数量、阶梯快捷项。
8. **生产方案**：同一工艺的多种生产方式（如数码/胶印、机器/手工）逐项比较成本与交期，选最优。
9. **计价发布**：平台利润率覆盖、发布状态；计价算法在「高级设置 → 资料库」维护。

```
商品 → 新建商品 → 非标报价 → 9 步
```

![9 步测算](docs/screenshots/builder.png)

路径：**后台 → 类目**。

- 新增 / 编辑类目名称、编码、上级类目、图片、说明、排序。

## 五、非标计价内核

### 5.1 成品尺寸 → 展开

后台选择展开结构并设置余量参数，前端输入成品长宽高即可自动换算。支持：

- 手提纸袋：`展开宽 = 2×袋宽 + 2×侧深 + 粘口`；`展开高 = 袋高 + 袋底 + 袋口折边`
- 插舌卡盒：`展开宽 = 2×长 + 2×宽 + 粘口`；`展开高 = 高 + 2×插舌`
- 天地盖：单片 `(长 + 2×高 + 2×余量) × (宽 + 2×高 + 2×余量)`，按盖+底 2 片/套
- 飞机盒、书型盒、瓦楞纸箱、标签、单页

展开后四周各加 **3mm 出血**（可配置），得到上机尺寸。

### 5.2 拼版与机型比选

- 把含出血展开件排到指定上机印张，考虑咬口、边距和 0°/90° 两种方向，取开数更大的方案。
- 每个「设备 × 印张」组合计算：一张拼几个、用纸张数、材料费、印刷费、成材率。
- 工艺方式也参与比选，例如手工糊袋 vs 机器糊袋、手工穿绳 vs 机器穿绳。
- 按成本优先或交期优先选出最终方案。
- 标签走卷筒分支，按卷宽、展开面积、卷长计算。

### 5.3 材料、辅料、工艺、包装

- 材料：克重、单位、图片、每 m²/张/件价格、可上机印张。
- 辅料：提绳、磁铁、内衬等，按米/件和单件用量计价。
- 工艺：图片、说明、适用盒型、材料种类、最低克重；一种工艺可配置多种生产方式（价格算法、交期、最低数量不同）。
- 包装：装箱数、箱重、箱规、包装费。
- 物流：杭州中心仓统一发货、送货上门；按重量/体积重计费，可配置起步价、续重、免运门槛。

### 5.4 价格口径

```
材料 + 印刷 + 工艺 + 辅料 + 包装
  + 管理费 + 物流 + 增值税
= 成本合计
  × (1 + 平台利润率) = 商品报价
```

非标商品不再经过代理商加价，直接输出商品报价。  
建品向导的「生产方案」「计价发布」页会展示成本、商品报价、单件报价和交期，方便运营校验。

### 5.5 多工厂 / 工厂价格表

每家报价工厂有自己的一套价格表，不是全局价乘系数。

后台路径：**高级设置 → 报价工厂 → 价格表**

| 价格表 | 内容 |
|---|---|
| 材料价格 | 每种材料在该工厂的单价、最低收费 |
| 工艺价格 | 每道工艺的每种生产方式：单价、版费、开机费、最低收费 |
| 设备价格 | 版费、调机费、千张印工、最低收费 |
| 包装价格 | 包装费、单件费 |

另外保留：

- **整单调整系数**：默认 1；特殊返点才用。
- **固定服务费**：默认 0。
- **交期偏移**、设备归属、启停。

建品时商品挂多个工厂。报价时：

1. 按每家工厂自己的价格表替换材料/工艺/设备/包装价；
2. 用该工厂自己的设备重新拼版；
3. 比较成本与交期；
4. 输出推荐工厂，前端只显示最终价格。

![工厂价格表](docs/screenshots/factory-prices.png)

演示数据：

| 数量 | 数码印刷中心 | 传统胶印厂 | 推荐 |
|---|---|---|---|
| 100 个 | ¥781.58 · 6-8 天 | ¥797.96 · 7-9 天 | 数码 |
| 500 个 | ¥2,800.98 · 6-8 天 | ¥1,436.72 · 7-9 天 | 胶印 |

### 5.6 物流交付：统一送货上门

非标建品第 6 步增加「物流交付」配置：

| 字段 | 说明 |
|---|---|
| 交付方式 | 送货上门（当前统一） |
| 发货仓 | 默认杭州中心仓 |
| 配送服务商 | 统一配送 / 顺丰 / 物流专线 |
| 起步运费 | 每单基础运费 |
| 每公斤续重 | 按实际重量/体积重计费 |
| 满额免运费 | 达到金额免运费；填 0 表示不免 |
| 配送时效 | 发货后预计天数 |
| 物流说明 | 前台展示，如「全国送货上门，偏远地区另议」 |

运费按包装后的实际重量/体积重自动计算，并计入商品报价；商品预览、手机前端和导出 JSON 都显示「送货上门」和运费规则。  
标准定价商品在表单里选择「售价含送货上门运费」或「运费另计」。

## 六点五、手机前端：非标报价器

后台建品不是终点：**后台配置规则，前端用这些规则让客户选规格、实时报价。**

独立手机页面：`#/m/{id}`

- 已上架商品可直接打开，不需要登录；可复制链接或从后台手机框打开。
- 非标商品可实时选择：
  - 尺寸预设 / 自定义长宽高
  - 材料、克重
  - 辅料（提绳、磁铁、内衬等）
  - 印刷颜色
  - 必选工艺 + 可选工艺
  - 包装方式
  - 数量
  - 一个起订量，数量即规格
- 打开页面不会直接给出默认报价：先选尺寸/材料/工艺/数量，再点「获取报价」。
- 第一次报价后，继续改规格会自动重算价格、交期和总价。
- 页面展示送货上门、发货仓、配送服务商、运费规则和预计时效。
- 公开页面只显示客户价格和报价明细，不显示成本、工厂名称和供应商。
- 后台手机框路径：`#/admin/products/{id}/mobile`，同样先点「获取报价」；之后管理员点「内部核价」看成本、成本明细、拼版、物流费和多工厂比价。
- 标准商品显示固定售价、SKU、起订量和含运费说明。
- 不提供下单/支付，最终价格以业务确认和合同为准。

## 七、给商品中心 / ERP

### 7.1 后台导出

- 商品列表右上角：**导出全部 JSON**。
- 每个商品卡片：单商品 **导出 JSON**。
- 商品预览页：**导出商品 JSON**。

### 7.2 ERP 拉取 API

设置里配置「ERP 集成密钥」，默认 `yxd-demo-key`。

```http
GET /api/integration/products?key=yxd-demo-key
GET /api/integration/products/{id}?key=yxd-demo-key
```

也支持请求头：

```http
X-Integration-Key: yxd-demo-key
```

只返回已上架商品。

### 7.3 分享给外部看

公开报价页是 `/m/{id}`，已上架商品不需要登录。

**同一 Wi-Fi / 局域网：**

```bash
HOST=0.0.0.0 python3 server.py
ipconfig getifaddr en0        # 查本机局域网 IP
```

然后手机打开：

```text
http://<电脑局域网IP>:8787/#/m/<商品ID>
```

后台商品 → 手机前端，页面右侧有「外部分享」：
- 用局域网地址打开后台时，复制出来就是局域网链接；
- 用 localhost 打开后台时，会提示只能本机访问。

**外网访问：**

当前没有内置公网地址。需要选一种：

- Cloudflare Tunnel：`cloudflared tunnel --url http://127.0.0.1:8787`
- ngrok：`ngrok http 8787`
- 部署到有域名的服务器，前面加 Nginx + HTTPS

公网分享前必须：

1. 修改管理员默认密码；
2. 用 HTTPS；
3. 确认只上架要公开的商品，草稿和未上架商品外部打不开；
4. 不要把后台地址直接发出去，只发 `/m/{id}` 公开页。

## 九、测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：

- 展开公式、出血、拼版开数、旋转、成材率。

## 十点五、部署到云端

本地 / 局域网只能同 Wi-Fi 访问；要给外部客户看，需要部署到有公网 IP 的服务器。

完整步骤见：[deploy/README.md](deploy/README.md)

最短流程：

```bash
# 云服务器上
curl -fsSL https://get.docker.com | sh
cd /opt/印小单/deploy
cp .env.example .env
# 编辑 DOMAIN=quote.yourdomain.com
docker compose --env-file .env -f docker-compose.prod.yml up -d --build
```

Caddy 会自动申请 HTTPS。  
分享地址：

```text
https://quote.yourdomain.com/#/m/商品ID
```

必需：域名 A 记录、80/443 开放、后台改默认密码。

## 十一、上线前建议

1. HTTPS + 反向代理；修改默认管理员密码。
2. 接入现有商品中心/ERP 的 SSO 或 API Key；不要把账号密码写在前端。
3. 确认类目字段与 ERP 类目树的映射（当前支持一级/二级 parent_id）。
4. 用真实纸价、工价、损耗、开机费替换演示参数，并用历史成交单校准。
5. 标准品价格以 ERP 为准；本工具只做建品信息补充，避免双写冲突。
6. 给导出/集成接口加限流、日志和重试；大批量同步建议走消息队列。
7. SQLite 备份/迁移 PostgreSQL；上传图片独立对象存储。
8. 如后续仍需报价/订单，可直接复用现有计价内核，但不要重复建商品主数据。
